# Python Keywords

## What are they?

Python keywords are protected words, which mean specific things and can't be used to name functions or variables.

| Word | Meaning                                                                                                                                                                                                                                                                         |
|------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| import | Used to import code from one file into another file (called a module) <br/><br/> `import python_file`                                                                                                                                                                           |
| from | To import specific parts of a module (if you only want to import specific classes and functions) <br/><br/> `from python_file import ThisIsMyFunction`                                                                                                                          |
| as | Used to create an alias for an imported module <br/><br/> `import python_file as pf` <br/><br/> Lots of people `import pandas as pd`.  This is so common, AI typically always does it.                                                                                          |
| and | Used to join two conditional statments together.  Both conditional statements must evaluate to True, else it is False.                                                                                                                                                          |
| not | Used to reverse the boolean value of a conditional.  not True == False and not False == True.                                                                                                                                                                                   |
| or | Used to join conditionals together.  If either condition is True then the conditional is True.                                                                                                                                                                                  |
| False | Boolean value, result of conditional operations                                                                                                                                                                                                                                 |
| True | Boolean value, result of conditional operations                                                                                                                                                                                                                                 |
| if | The body of an if statement is executed if the condition evaluates to True                                                                                                                                                                                                      |
| elif | The body of an elif statement is executed if the if condition evaluates to False and the elif condition evaluates to True                                                                                                                                                       |
| else | The body of an else statement is executed if the if condition evaluates to False and all subsequent elif conditions evaluate to False                                                                                                                                           |
| assert | Assert on a condition.  If the condition is false then an AssertionError is raised. <br/><br/> For example this would raise an AssertionError with the specified message <br/><br/> `assert 2==3, '2 IS SUPPOSED TO EQUAL 3'`                                                   |
| match | (requires python3.10+) If you have a variable and you want to do different things then you should use match with each case you want to handle.  This control flow can also be managed with if-elif-else control flow.                                                           |
| case | (requires python3.10+) If the pattern is matched then run the body of the case.                                                                                                                                                                                                 |
| class | To define a class                                                                                                                                                                                                                                                               |
| def | To define a function                                                                                                                                                                                                                                                            |
| try | To make a try...except statement.  Allows you to run some code and except certain errors.                                                                                                                                                                                       |
| except | Excepts certain errors and with a body that specifies how to handle them.                                                                                                                                                                                                       |
| raise | To raise an exception.  Halts execution of current call stack frame and raises it to the next portion of the call stack.                                                                                                                                                        |
| finally | Used with try...except, a block of code that will be executed no matter if there is an exception or not                                                                                                                                                                         |
| None | Represents a null value.  Nada.                                                                                                                                                                                                                                                 |
| pass | All functions and conditionals need a body (something after dos puntos).<br/><br/> this allows you to have a body that does nothing.  This is often used when creating tests where you want to stub out some behavior and do nothing and also used for unimplemented functions. |
| for | Used with the keyword `in` to loop through structures with multiple values.                                                                                                                                                                                                     |
| in | To check if a value is present in a list, tuple, dict, set.  Mandatory for for-loops, but can also be used in conditionals.                                                                                                                                                     |
| while | To create a while loop.  The simplest while loop is `while True:`, but any condition could take the place of true.                                                                                                                                                              |
| break | To break out of a loop and not run any more iterations even if the condition for looping is still True.                                                                                                                                                                         |
| continue | Like pass only for loops. Continues to the next iteration of a loop.  Say for each number 1-10 you want to print the number except for 2.<br/><br/>`for x in range(11): if x == 2: continue print(x)`                                                                           |
| return | Exits a function and returns a value.  Multiple values can be returned.  Nothing else will persist from the function state other than these values and any specially declared variables.  Changes to mutable objects will also persist without returning.                       |
| with | Used with input-output (I/O) to handle resources.  Not properly closing files or databases with python causes loads of problems.  Declaring the I/O resource using with means Python will work magic to ensure long living connections do to program error never happen.        |
| del | To delete an object.  Can be used to remove a key from dictionaries, along with dictionary.pop("key"), which is function on the dictionary object that returns the key's value.                                                                                                 |
| yield | You can setup functions that return (yield) multiple values.  You get each value by calling next(returned_object_from_function).                                                                                                                                                |
| lambda | A special type of function.  code_to_test.py uses a lambda                                                                                                                                                                                                                      |
| async | Define a special type of function that kicks off while the control flow continues to execute.                                                                                                                                                                                   |
| await | Wait for and get a result from an async method invocation.                                                                                                                                                                                                                      |
| is | To test if two variables are equal.  Typically you'll want to use == instead.  This is for object equivalence.  We'll get into objects in lección 3.                                                                                                                            |
| global | To declare a global variable for a module.  Global state is a nightmare to maintain and should be used sparingly.                                                                                                                                                               |
| nonlocal | To extend a variable's scope inside nested functions.  Typically variables declared within functions are local variables. In other words, they can't be used or referenced outside of the function they were declared in.                                                       |
